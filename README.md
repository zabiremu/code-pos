# Restaurant POS (CodeCanyon Edition)

A Laravel-based Point-of-Sale system built for restaurants and cafes,
targeting submission to Envato CodeCanyon.

**Status:** Phase 1 (Foundation) — domain schema, models, roles, and a base
admin layout are written. This repo does **not** yet contain the Laravel
framework skeleton or `vendor/` (see Setup below for why and how to add it).

Full build plan (feature modules, database schema, architecture, Envato
compliance checklist, installer design, packaging, milestones) lives in the
project's Claude Docs plan.

## Stack
- Laravel 11.x on PHP 8.2+
- MySQL 8 (production) / SQLite is fine for local dev
- Blade + Alpine.js + Tailwind CSS (via Laravel Breeze)
- spatie/laravel-permission (roles), Laravel Sanctum (API auth)
- Laravel Echo + self-hosted Soketi/Pusher for the Kitchen Display System,
  with a polling fallback for shared-hosting installs

## Setup

This repo currently holds only the **application layer** (migrations,
models, controllers, routes, seeders, views) — not the Laravel framework
skeleton itself, since that's generated by Composer rather than hand-written.
To get a running install:

```bash
# 1. Scaffold a fresh Laravel 11 app in a temp folder
composer create-project laravel/laravel:^11.0 _skeleton
# 2. Copy the skeleton's framework files into this repo (everything except
#    what this repo already defines: app/Models, app/Http/Controllers,
#    database/migrations, database/seeders, routes/web.php, resources/views)
rsync -a --ignore-existing _skeleton/ .
rm -rf _skeleton

# 3. Install this project's actual dependencies
composer install

# 4. Auth scaffolding (Blade + Alpine + Tailwind)
composer require laravel/breeze --dev
php artisan breeze:install blade

# 5. Roles package migrations
composer require spatie/laravel-permission
php artisan vendor:publish --provider="Spatie\Permission\PermissionServiceProvider"

# 6. Register the `role` middleware alias in bootstrap/app.php:
#    ->withMiddleware(function (Middleware $middleware) {
#        $middleware->alias(['role' => \Spatie\Permission\Middleware\RoleMiddleware::class]);
#    })

cp .env.example .env
php artisan key:generate
php artisan migrate --seed   # seeds roles + a demo admin (admin@example.com / password)
npm install && npm run build
php artisan serve
```

> I couldn't run `composer create-project` or install packages from the
> sandbox this was built in — its network policy blocks Packagist — so
> these steps are written out but not yet execution-tested end to end.
> Run through them once and flag anything that doesn't line up.

## What's here (Phase 1)

- `database/migrations/` — full schema: branches, floors, tables, menu
  categories/items/variants/modifiers, ingredients, orders, bills, payments,
  shifts, stock movements, discounts
- `app/Models/` — matching Eloquent models with relationships
- `app/Enums/Role.php` + `database/seeders/RolesAndAdminSeeder.php` — the
  five POS roles (admin/manager/cashier/waiter/kitchen) and a demo admin
- `app/Http/Controllers/Admin/DashboardController.php`,
  `app/Http/Controllers/POS/OrderController.php` — starting shape for the
  admin and waiter-facing sides
- `routes/web.php` — role-gated route groups
- `resources/views/layouts/admin.blade.php` + `admin/dashboard.blade.php` —
  base admin shell

Menu/table management UI, the Kitchen Display System, billing, reports, the
web installer, and Envato purchase-code verification are the next phases —
see the build plan for the full breakdown.
