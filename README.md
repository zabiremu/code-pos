# Restaurant POS (CodeCanyon Edition)

A Laravel-based Point-of-Sale system built for restaurants and cafes,
targeting submission to Envato CodeCanyon.

**Status:** Architecture & planning phase — no application code yet.

Full build plan (feature modules, database schema, architecture,
Envato compliance checklist, installer design, packaging, milestones)
lives in the project's Claude Docs plan.

## Stack (planned)
- Laravel (latest LTS-equivalent stable release) on PHP 8.x
- MySQL
- Blade + Alpine.js + Tailwind CSS (admin/POS UI)
- Laravel Echo / broadcasting for the kitchen display system
